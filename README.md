# 동맛 (Dongmat) 안내서

## 1. 내 컴퓨터에서 실행하기
서비스 워커(오프라인·설치 기능)는 파일을 더블클릭해서는 동작하지 않고, 간이 서버가 필요해요.
- 방법 A (VS Code): "Live Server" 확장 설치 → index.html 우클릭 → Open with Live Server
- 방법 B (파이썬): 이 폴더에서 터미널을 열고 `python3 -m http.server 8000` 입력 → 브라우저에서 http://localhost:8000 접속

## 2. GitHub Pages 배포
1. GitHub에서 새 저장소(Repository)를 만듭니다. (Public 권장)
2. 이 폴더 안의 파일과 폴더를 전부 업로드합니다. index.html이 저장소 맨 위에 있어야 해요.
3. 저장소의 Settings → Pages → Branch를 main, 폴더를 /(root)로 선택하고 Save.
4. 1~2분 뒤 안내되는 주소(https://아이디.github.io/저장소이름/)로 접속합니다.
모든 경로가 상대경로라서 저장소 이름이 달라도 그대로 동작해요.

## 3. 스마트폰에 설치
- 안드로이드(Chrome): 설정 화면의 "앱 설치하기" 버튼 또는 브라우저 메뉴 → "앱 설치"
- 아이폰(Safari): 하단 공유 버튼 → "홈 화면에 추가"
(설치는 https 주소, 즉 GitHub Pages에서만 가능해요.)

## 4. 음식점 데이터 관리 (data/restaurants.json)
지금 들어 있는 3곳은 "예시 데이터"이며 실제 가게가 아니에요. 화면에도 "예시 데이터" 표시가 붙습니다. 실제 데이터를 넣을 때는 예시 3곳을 지우세요.

필수: id(겹치지 않게), name, lat, lng (위치가 있어야 반경 검색·지도에 나와요)
선택: category(한식/중식/일식/양식/분식/카페/기타), address, phone, hours, photo(이미지 주소), rating, reviews, popularity, menu
```
{"id":"1","name":"가게 이름","category":"한식","address":"주소","lat":37.5665,"lng":126.978,
 "phone":"02-000-0000","hours":"11:00~21:00","photo":"data/photos/1.jpg",
 "rating":4.5,"reviews":120,"popularity":80,
 "menu":[{"name":"칼국수","price":9000}]}
```
- 항목 사이는 쉼표(,)로 구분하고 마지막 항목 뒤에는 쉼표를 넣지 않아요.
- 값이 없는 항목은 아예 적지 마세요. 화면에 "정보 없음"으로 표시돼요.
- 평점·리뷰 수·인기도가 한 곳도 없으면 해당 정렬 기준은 자동으로 비활성화돼요.
- 데이터를 고친 뒤에는 service-worker.js 맨 위 'dongmat-v2'를 'dongmat-v3'처럼 바꿔야 설치된 앱에도 반영돼요.

## 5. 지도·API 안내 (중요)
- 지도: OpenStreetMap + Leaflet. API 키가 필요 없어요. 지도 타일은 무료 서버라서 트래픽이 많은 공개 서비스에는 맞지 않을 수 있어요.
- 주소 검색: OpenStreetMap Nominatim(무료). 이용 정책상 과도한 호출은 안 돼요. 국내 상세 주소는 정확도가 낮을 수 있어요.
- 네이버/카카오 지도 API는 연동하지 않았어요. 사용하려면 각 개발자 센터에서 키를 발급받고 **허용 도메인을 GitHub Pages 주소로 제한**해야 합니다. 키는 공개 저장소에 그대로 노출되므로 도메인 제한이 안 되는 키는 넣지 마세요.
- 실시간 평점·리뷰·방문자 수는 외부 API 없이는 가져올 수 없어서, 직접 입력한 값만 표시해요.
- 길찾기는 각 지도 서비스의 웹 링크로 연결돼요. 네이버 지도는 가게 검색 결과로 이동해요.
